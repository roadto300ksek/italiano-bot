# Italiano Bot — Telegram-бот для изучения итальянского

Бот-тренажёр итальянского языка: диалоги с LLM, разбор грамматики, случайные слова с ассоциациями и озвучка ответов.

## Что умеет

- **Персонажи** — 4 стиля общения на выбор, у каждого своя манера и подача.
- **Диалог на итальянском** — ответы с переводом на русский, история переписки, очистка истории.
- **Грамматика** — объяснение правил по запросу.
- **Слова** — случайное слово с переводом, примером употребления и ассоциацией для запоминания.
- **Озвучка** — синтез итальянской части ответа через edge-tts.
- **Защита от злоупотреблений** — антифлуд (5 сообщений за 60 секунд), дневной лимит (100 сообщений), ограничение длины сообщения (500 символов), фильтр prompt-инъекций по стоп-фразам, очистка итальянского текста перед синтезом.

## Стек

- Python 3
- python-telegram-bot 20+ (асинхронные хендлеры, callback-кнопки)
- OpenAI SDK (совместимый API, например DeepSeek)
- edge-tts
- Flask (обёртка для деплоя)

## Структура

```
app.py              — запуск бота и Flask-обёртка
bot/handlers.py     — команды, диалоги, callback-кнопки
bot/characters.py   — персонажи и промпты
bot/security.py     — антифлуд, дневные лимиты, защита от инъекций
bot/utils.py        — вспомогательные функции
bot/config.example.py — шаблон конфигурации
```

## Запуск

```bash
pip install -r requirements.txt
cp bot/config.example.py bot/config.py
```

В `bot/config.py` укажите `TELEGRAM_TOKEN` и `DEEPSEEK_API_KEY`.

```bash
python app.py
```

## Деплой

Проект рассчитан на запуск на PythonAnywhere: Flask-обёртка держит процесс, бот работает в отдельном потоке с собственным event loop.

## Что демонстрирует

Асинхронные Telegram-хендлеры, интеграцию LLM через OpenAI SDK, работу с внешним TTS-сервисом, защиту от инъекций и флуда, конфигурацию через переменные окружения и деплой в прод.
