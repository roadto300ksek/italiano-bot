# Italiano Bot — Telegram-бот для изучения итальянского

Бот-тренажёр итальянского языка: диалоги с LLM, разбор грамматики, случайные слова с ассоциациями и озвучка ответов.

## Что умеет

- **Персонажи** — 4 стиля общения на выбор, у каждого своя манера и подача.
- **Диалог на итальянском** — ответы с переводом на русский, история переписки, очистка истории.
- **Грамматика** — объяснение правил по запросу.
- **Слова** — случайное слово с переводом, примером употребления и ассоциацией для запоминания.
- **Озвучка** — синтез итальянской части ответа через gTTS.
- **Защита от злоупотреблений** — антифлуд (5 сообщений за 60 секунд), дневной лимит (100 запросов), ограничение длины сообщения (500 символов), лимиты для callback-кнопок, фильтр prompt-инъекций по стоп-фразам, очистка итальянского текста перед синтезом.

## Стек

- Python 3.10
- python-telegram-bot 22.8 (асинхронные хендлеры, callback-кнопки)
- OpenAI SDK 2.53 (совместимый API, например DeepSeek)
- gTTS 2.5.4
- Flask 3.1

## Структура

```
app.py              — Flask-обёртка и запуск polling в фоновом потоке
bot/handlers.py     — команды, диалоги, callback-кнопки
bot/characters.py   — персонажи и промпты
bot/security.py     — антифлуд, дневные лимиты, защита от инъекций
bot/utils.py        — DeepSeek, TTS, клавиатуры
bot/main.py         — альтернативный entrypoint только для polling
bot/config.example.py — шаблон конфигурации
```

## Запуск

```bash
pip install -r requirements.txt
cp bot/config.example.py bot/config.py
```

В `bot/config.py` укажите `TELEGRAM_TOKEN` и `DEEPSEEK_API_KEY`.

```bash
python app.py
```

`app.py` поднимает Flask и запускает polling в фоновом потоке. Для запуска без Flask:

```bash
python -m bot.main
```

## Проверка состояния

После запуска доступен health-check:

```
GET /healthz
```

Он возвращает `200`, если polling-поток запущен, и `503` с текстом ошибки, если нет.

## Деплой на PythonAnywhere

Проект рассчитан на запуск на PythonAnywhere: Flask-обёртка держит процесс, бот работает в отдельном потоке с собственным event loop.

1. Web-приложение указывает на каталог проекта и virtualenv `myenv`.
2. WSGI-файл импортирует `app` из `app.py`.
3. После `git push` на GitHub код на PythonAnywhere сам не обновляется. Нужно вручную:

```bash
cd ~/italiano-bot
git pull origin main
```

4. Затем перезагрузить web-приложение (Web → Reload) или вызвать API reload.

Автоматического деплоя сейчас нет.

## Ограничения

- История, выбранный персонаж и лимиты хранятся в памяти процесса и теряются при reload.
- Для корректной работы нужен один процесс: при нескольких workers состояние и polling расходятся.
- Дневной лимит считается по UTC (времени сервера).

## Что демонстрирует

Асинхронные Telegram-хендлеры, интеграцию LLM через OpenAI SDK, работу с внешним TTS-сервисом, защиту от инъекций, флуда и злоупотребления кнопками, health-check, конфигурацию через отдельный модуль и деплой в прод.
